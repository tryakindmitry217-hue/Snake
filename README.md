# Snake

Консольная игра «Змейка» на C#, разработанная как экзаменационный проект. Приложение демонстрирует основные принципы объектно-ориентированного программирования и базовые элементы языка C#.

## Возможности

- Консольная игра «Змейка» с управлением нажатием клавиш.
- Змейка питается и растёт при поедании еды.
- Игра прекращается при столкновении с препятствиями или собственным хвостом.
- Демонстрация принципов ООП:
  - инкапсуляция;
  - наследование;
  - полиморфизм;
  - абстрагирование.
- Использование элементов языка C#:
  - перечисления (`enum`);
  - встроенный класс списка (`List`);
  - работа с файлами и директориями.

## Требования

- .NET (версия, совместимая с проектом).
- Операционная система: Windows, Linux или macOS.

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/your-repo/Snake.git
```

Перейдите в директорию проекта:

```bash
cd Snake
```

Соберите проект:

```bash
dotnet build
```

## Использование

Запустите приложение:

```bash
dotnet run
```

После запуска начинается консольная игра. Змейка контролируется нажатием клавиш, питается и растёт. При столкновении с препятствиями или собственным хвостом игра прекращается.

## Техническое описание

**Сущности:** точка, фигура, вертикальная линия, горизонтальная линия, змейка.

**Функционал:** змейка контролируется нажатием клавиш, питается, растёт. При столкновении с препятствиями или собственным хвостом игра прекращается.

**Реализация представлена в классах:**

- `Figure`;
- `VerticalLine`;
- `HorizontalLine`;
- `Snake`;
- `FoodCreator`;
- `Point`;
- `Walls`;
- `Direction`;
- `Program` — основной класс.
